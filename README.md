# Adam Elsayed ePortfolio

A responsive, single-page ePortfolio for Adam Elsayed, Georgia Tech Computer Engineering student. It includes the required introduction, biography, career roadmap, resume links, and a 400+ word Discovery Project feature.

## Local preview

Open `dist/index.html` in a browser, or serve the `dist/` directory with any static HTTP server.
